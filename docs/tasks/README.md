# Контекст отдельных задач

Задачи и планы ведутся в Git issues владельцем проекта; отдельный список задач здесь не нужен. Каталог оставлен для дополнительного контекста сложных задач при необходимости. Не дублировать трекер, не помещать секреты и персональные данные.

После реализации каждой функции или исправления ошибки обновлять соответствующую документацию по фактическому поведению и выполненным проверкам. Ещё не реализованные возможности не описывать как существующие.

Текущее поведение проекта описывается в `docs/architecture.md`, общие инструкции — в `AGENTS.md`. Документ задачи хранит требования, согласованные решения и результаты проверок; он не должен оставаться единственным описанием реализованной функции.

Для завершённых задач рекомендуется `docs/tasks/archive/`. После проверки итоговой документации владельцем документ можно перенести туда, обновив ссылки. Архив хранит историю и не является источником новых задач или обязательными инструкциями для текущей работы. Для маленькой задачи читать архив не требуется. Сейчас складской документ оставлен на месте до проверки владельцем; каталог архива ещё не создан.

Общие инструкции — [AGENTS.md](../../AGENTS.md), текущее устройство — [architecture.md](../architecture.md). Для маленькой задачи достаточно относящегося к ней контекста.
